# Tkinter examples (Python implementation only)

These examples use the `window(...)` and `canvas(...)` functions from the older Python implementation (`kiln.py`), which draws with Tkinter. They do not run on the native runtime (`kiln`), which uses raylib for graphics (see `examples/native_gui.kiln`).

To run them, install Tkinter (`sudo apt install python3-tk` on Debian or Ubuntu) and then run:

    python3 kiln.py examples/tk/gui_hello.kiln
